# AgentPost v0.3.0 —— 底栏导航、同步加固 🧭

> 📖 Language · 语言：**简体中文** · [English](v0.3.0.en.md)
>
> **发布日期**：2026-09-20
> **代号**：Tabbed Inbox

继 v0.2.0「Portable Mail」打通配置迁移与签名发布之后，v0.3.0 聚焦「**更快抵达、更稳在线**」两件事：**底部标签栏**让任务 / 归档 / 设置三个核心入口一键切换；围绕 IMAP 同步的一揽子加固（**UIDVALIDITY 校验与自动回溯**、错误分类重试、全量重扫）根治「换了邮箱 / 服务端重建收件箱后收不到新邮件」这类隐蔽问题；推送服务则配上**开机自启 + 看门狗 + 唤醒锁**三保险，并新增**局域网在场广播**。此外还顺手解决了一个"看不见"的问题： APK 体积从 73MB 回落到约 34MB。

---

## ✨ 核心亮点

- 🧭 **底部标签栏导航**：任务 / 归档 / 设置提升为三个顶层标签，一键直达；切换时保留各标签页状态，下钻页自动隐藏底栏
- 🔁 **IMAP UIDVALIDITY 自动回溯**：检测到服务端收件箱重建后，自动回溯最近 7 天邮件、矫正同步水线，之后恢复纯增量拉取 —— 根治"换邮箱 / 重建收件箱后收不到新邮件"
- 🛡️ **推送常驻三保险**：开机自启（BootCompletedReceiver）+ WorkManager 看门狗周期巡检 + 唤醒锁持有；被国产 ROM 杀掉或误划任务卡片后服务自动复活
- 📡 **局域网在场广播**（lan-beacon v0.2.0）：同一 WiFi 下向局域网宣告设备在场，设置页可开关、可配端口、实时显示本机 IP
- 🧹 **收件箱自救工具箱**：邮件设置页新增「重新全量拉取」一键修复漏收；未分类消息支持一键清空
- 📦 **APK 大幅瘦身**：移除误引入的 material-icons-extended，"归档"图标改用 1.2KB 本地矢量图，debug APK 从 73.21MB 回落到约 34MB

---

## 🚀 变更清单

### 导航与界面

- ✅ **底部标签栏**：
  - 任务 / 归档 / 设置三个顶层标签，声明顺序即底栏从左到右顺序
  - 切换标签走官方 saveState / restoreState 模式：切走再切回不重建页面、保留列表滚动位置
  - 下钻页（详情 / 新建 / 未分类 / 设置二级页）自动隐藏底栏，由顶栏返回键或系统返回键退出
  - 归档与设置从任务页顶栏溢出菜单提升为一级入口，顶栏不再显示返回按钮
- ✅ **任务列表交互优化**：
  - 长按弹上下文菜单（归档 / 删除），替代原批量选择模式
  - 新增任务删除功能，弹确认对话框防误操作
  - 消息内容支持文本选择，便于复制引用
- ✅ **「关于」弹框**：设置页新增关于入口，点击显示当前应用版本号

### 邮件同步与推送（本版重头戏）

- ✅ **IMAP UIDVALIDITY 支持**：
  - 校验服务器 INBOX 的 UIDVALIDITY，检测到服务端重建即触发回溯
  - 回溯窗口只拉取最近 7 天邮件（带兜底消息数），避免整箱全扫；回溯完成后水线推到当前最高 UID，之后纯增量
  - 拉取与 IDLE 推送统一走 UIDVALIDITY + lastSyncUid 的水线推进，持久化保存
- ✅ **修复「更换邮箱后收不到新邮件」**：
  - 账号槽位复用时重置 lastSyncUid，防止新邮件被旧水线永久过滤
  - 取消基于未读状态的拉取过滤，改用 UID 增量拉取
  - 兼容 QQ 邮箱别名切换导致的"邮箱变更"场景
- ✅ **同步错误分类与重试策略**：鉴权失败等永久性错误直接标记失败并提示重新配置；网络类临时性错误自动重试，不再一刀切失败
- ✅ **全量重扫收件箱**：邮件设置页新增「重新全量拉取」按钮，修复增量水线被推过头导致的漏邮件；已入库邮件按 Message-ID 去重，不会重复出现
- ✅ **单封解析失败不再丢信**：FetchBatch 区分成功解析与解析失败的 UID，水线不因单封坏邮件卡死或跳过；无 Message-ID 的邮件合成稳定伪 ID
- ✅ **IMAP IDLE 推送稳健性**：session 管理收紧，长连接断开自动重建，异常路径日志补齐

### 未分类消息

- ✅ **一键清空**：未分类页新增清空按钮，确认后删除全部未分类消息及其本地附件，完成后 Snackbar 汇报条数；仅删消息、保留占位任务行，维护与邮箱端的同步兼容性

### 常驻在线

- ✅ **局域网在场广播**（lan-beacon v0.2.0）：
  - 设置页新增开关与端口配置，实时显示当前 WiFi IP 与广播状态
  - 前台服务扩展为双职责：IMAP IDLE 实时推送 + 局域网广播子组件，两个开关共同控制服务启停
  - 依赖切换为 JitPack 发布版本（`com.github.szgenle:lan-beacon:v0.2.0`），同时保留本地 composite build 便于联调
- ✅ **开机自启**：新增 BootCompletedReceiver，开机后按偏好自动重启推送服务；服务持有部分唤醒锁维持长连接；用户划掉任务卡片后 5 秒自动重启
- ✅ **推送看门狗**：WorkManager 周期性健康检查前台服务活性，配置开启而服务被杀时自动拉起，专治国产 ROM "杀服务不重启"

### 工程与体积

- ✅ **APK 瘦身 39MB**：移除误引入的 `material-icons-extended`（该库携带 5000+ 图标，而 App 仅用 1 个），"归档"底栏图标改用本地矢量资源 `ic_archive.xml`（约 1.2KB）；debug APK 从 73.21MB 回落到约 34MB，回归项目"坚持不用 extended"的资源约定
- ✅ **lan-beacon 依赖治理**：源码 composite build 与 JitPack 发布版本双轨并行，本地调试改源码、正式构建锁版本

## 📋 系统要求

| 项 | 要求 |
|---|---|
| Android 版本 | 9.0+（API 28，覆盖 ~94% 设备） |
| 网络 | 能访问你选择的 IMAP / SMTP 服务器；局域网在场广播需与对端处于同一 WiFi |
| 权限 | 网络 / 前台服务（数据同步与局域网广播） / 通知 / 开机自启（可选，用于推送常驻） / 忽略电池优化（实时推送用） |
| 邮箱要求 | 任意支持 IMAP + SMTP 的邮箱（Gmail / 163 / QQ / 企业自建均可） |

## 📦 安装

### 预编译 APK（推荐）

直接下载本 Release Assets 中的 `app-release.apk`（已由作者 keystore 签名），覆盖安装即可。

### 从源码构建

```bash
git clone https://github.com/szgenle/agentpost.git
cd agentpost
./gradlew :app:assembleDebug
# APK 产物：app/build/outputs/apk/debug/app-debug.apk
```

如需本地产出已签名 release APK，参考 `Makefile` 中 `build-release` / `sign-release` / `verify-release` 目标。

## ⚠️ 已知限制

1. **发送端附件** 仍从 `content://` URI 读取字节流发送，本地不落盘；已发送附件点击会提示"不可下载"
2. **Android 14+ 前台服务** 启用实时推送需要手动加入电池白名单；部分国产 ROM 还需在系统设置中授予「自启动」权限，开机自启与看门狗才能生效
3. **Gmail** 需使用 App Password（2FA 后在账户安全设置里生成）
4. **IMAP IDLE** 仍标记为实验功能，长时驻留稳定性已通过看门狗大幅改善，但仍在持续观察中
5. **配置导出** 仅覆盖账号 / 模板 / 偏好，**不包含**任务与消息历史（任务数据请通过邮箱本身的同步恢复）
6. **局域网在场广播** 仅在同一局域网内可见，跨网段 / 访客网络下不可用
