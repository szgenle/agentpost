# AgentPost v0.2.0 — Portable Config & Signed Releases 🚚

> 📖 Language · 语言：[简体中文](v0.2.0.md) · **English**
>
> **Release Date**: 2026-05-17
> **Codename**: Portable Mail

Following the v0.1.0 "First Mail" inaugural open source release, v0.2.0 focuses on making AgentPost **truly portable across devices and properly distributable**: a complete **encrypted config import/export** pipeline, a refined **settings page taxonomy**, and an end-to-end **signed-build & CI auto-release** flow built around a reusable keystore — plus a batch of polish items born out of real usage.

---

## ✨ Highlights

- 📦 **Encrypted config import/export**: Pack accounts, command templates and app preferences into a single encrypted file. Migrate or reinstall and import in one step. Password reuses the "encrypted attachment master password" concept — zero external dependencies
- 🗂️ **Settings page regrouping**: The flat "Other" group is split into two semantic groups: **Mail processing** and **Application**, making accounts / sync / templates / security / about easier to locate
- 🔐 **Signed release APK pipeline**: `app/build.gradle.kts` reads four `SIGNING_*` env vars and conditionally enables release signing. Local `make build-release` / `make sign-release` and CI on tag push will both produce a signed APK, with CI auto-attaching it to the GitHub Release
- ✅ **APK signature verification**: New `make verify-release` target cross-checks the APK signing certificate against the keystore fingerprint via `apksigner` + `keytool`, eliminating the "we shipped an APK signed by the wrong keystore" class of mistakes
- 🎨 **Adaptive launcher icon**: `mipmap-anydpi-v26` resources added, ensuring consistent rendering on Android 8+ launchers (round / squircle / teardrop)
- 🔁 **IMAP IDLE robustness**: Better exception logging and tighter reconnect cadence — more reliable on long-running sessions and weak networks

---

## 🚀 Change List

### Settings & Configuration (the headline area)

- ✅ **Config import/export**:
  - Export: Bundle dual-account config (IMAP/SMTP), command templates and app preferences into a single encrypted file
  - Import: Pick file → enter password → choose merge strategy (overwrite / skip-existing)
  - Encryption: Reuses the master-password concept; if no master password exists, the flow guides you to set one first
  - Fixed an edge case where "first import fails, retries also fail"
- ✅ **Settings regrouping**: The previously flat "Other" group was split into:
  - **Mail processing**: Accounts, sync strategy, IMAP IDLE, command templates
  - **Application**: Language, theme, config import/export, About
- ✅ **Password field placeholder**: When a saved password exists, the input now shows a masked placeholder (e.g. `••••••••`) clearly signalling "leave empty to keep the existing one"
- ✅ Removed the Debug-only crash trigger entry to prevent accidental taps

### Engineering & Release

- ✅ **End-to-end signed release pipeline**:
  - `app/build.gradle.kts` enables release signing only when all 4 `SIGNING_*` env vars are present, gracefully falling back to unsigned builds otherwise
  - `Makefile` adds `build-release`, `sign-release`, `verify-release` targets
  - Fixed a subtle `Makefile` bug where `~` was not expanded inside double quotes, breaking keystore paths
- ✅ **CI auto-release upgrade**:
  - On `refs/tags/v*` pushes, GitHub Actions now base64-decodes the keystore → injects passwords → runs `assembleRelease` → uploads the signed APK to the Release, with zero manual steps
  - An `always()` cleanup step removes the temporary keystore from the runner
- ✅ **APK / keystore fingerprint cross-check**: `verify-release` validates SHA-256 fingerprints in both directions

### Polish

- ✅ **Adaptive launcher icon**: Added `ic_launcher.xml` / `ic_launcher_round.xml` adaptive resources
- ✅ **IDLE push reliability**: Filled in exception-branch logs and tightened reconnect backoff
- ✅ **IDLE noise reduction**: No more dense foreground polling warnings when no mailbox is configured

## 🆚 Compatibility vs v0.1.0

- **Database / data formats**: Fully backwards compatible. Upgrading from v0.1.0 to v0.2.0 requires no manual migration
- **Config export file**: v0.2.0 is the first format version; future releases will preserve backwards-compatible read support
- **versionCode**: bumped from `1` to `2`; over-the-top install supported

## 📋 Requirements

| Item | Requirement |
|---|---|
| Android version | 9.0+ (API 28, ~94% device coverage) |
| Network | Access to your chosen IMAP / SMTP servers |
| Permissions | Internet / Foreground Service (data sync) / Notifications / Battery optimization exemption (for realtime push) |

## 📦 Installation

### Prebuilt APK (recommended)

Download `app-release.apk` from this Release's Assets (signed with the author's keystore) and install over your existing copy.

### Build from source

```bash
git clone https://github.com/szgenle/agentpost.git
cd agentpost
./gradlew :app:assembleDebug
# Output: app/build/outputs/apk/debug/app-debug.apk
```

To produce a signed release APK locally, see the `build-release` / `sign-release` / `verify-release` targets in `Makefile`.

## ⚠️ Known Limitations

1. **Sent-side attachments** are still streamed from `content://` URIs without local persistence; tapping a sent attachment shows "not downloadable"
2. **Android 14+ Foreground Service** — enabling realtime push requires manual battery whitelist
3. **Gmail** requires an App Password (generate under account security after enabling 2FA)
4. **IMAP IDLE** is still marked experimental; long-term background stability is under continued observation
5. **Config export** only covers accounts / templates / preferences, **not** task & message history (recover task data via mailbox sync itself)
