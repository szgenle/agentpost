# AgentPost v0.1.0 —— First Open Source Release 🎉

> 📖 Language · 语言：[简体中文](v0.1.0.md) · **English**
>
> **Release Date**: 2026-05-XX (TBD)
> **Codename**: First Mail

The first public release of AgentPost — an Android app that uses **standard email protocols** as an asynchronous channel, purpose-built for "remotely commanding your home AI agent while you're away." It repackages the generic capabilities of an email client into a mobile console focused on "task dispatch / result retrieval."

---

## ✨ Highlights

- 📮 **Pure standard email protocols**: IMAP + SMTP, zero custom protocol, zero custom headers — **works with any mailbox, zero changes on the agent side**
- 🧵 **Task-centric aggregation**: Home screen is a task pool, not an inbox; detail view is a timeline, not chat bubbles; Message-ID thread chain + Subject `Re:` fallback routing
- ⚡ **Dual-mode sync + smart realtime push**: 30s foreground polling + 15min background WorkManager by default; optional IMAP IDLE realtime push with built-in **adaptive heartbeat learning** (dynamically tuned between 30s~9min to approximate pure IDLE while guaranteeing no missed mail)
- 🔒 **Privacy-first**: Credentials stored in `EncryptedSharedPreferences` + Android Keystore; crash reports routed through your own SELF mailbox — no third-party platforms
- 🌐 **Bilingual**: Full Simplified Chinese + English coverage with per-app locale switching

## 🚀 Feature List

### Mail & Tasks

- ✅ Account setup: SELF (sender) + AGENT (receiver) dual accounts, separate IMAP / SMTP config
- ✅ Task creation & reply: Markdown support, attachment picker (10 MB limit), one-tap template fill
- ✅ Message-ID thread routing + Subject fallback + "Unclassified" panel (three-level fallback)
- ✅ Task list: card layout, unread badges, last-message preview, relative timestamps
- ✅ Task detail: timeline rendering, Markdown + code highlighting, attachment inline preview entry

### Task Archiving (full loop)

- ✅ **Archived tasks page**: Overflow menu (⋮) on task list top bar → "Archived", a dedicated secondary page where each item supports "Restore"
- ✅ **Per-task archive in detail**: ⋮ menu on task detail archives the task in one tap, auto-navigates back to list with Snackbar feedback
- ✅ **Long-press batch archive on home**: Long-press any task card to enter multi-select mode; supports multi-select / select-all / batch archive; system back key exits selection mode; partial-success feedback on batch
- ✅ **Hard delete archived tasks**: The archived page supports permanently deleting a task along with all its messages and attachments
- ✅ All paths explicitly filter the `__UNCLASSIFIED__` placeholder task to avoid accidentally archiving the fallback container

### Sync & Notifications

- ✅ Foreground 30s coroutine polling + background 15min WorkManager fallback
- ✅ **IMAP IDLE smart realtime push** (experimental): Foreground Service + sticky notification; **adaptive heartbeat learning algorithm** — on every `idle()` return, classifies along two axes (server-initiated wake vs heartbeat-kick wake + whether new mail was actually drained) and dynamically tunes the heartbeat interval (hit new mail ×2 expand, empty kick ×2 shrink, idle period ×1.2 slow-expand), clamped to 30s floor / 9min ceiling; exponential backoff reconnect on disconnect
- ✅ System notifications with deep-link to task detail; Android 13+ `POST_NOTIFICATIONS` handled
- ✅ Pull-to-refresh (Material 3 `PullToRefreshBox`)

### Attachments & Encryption

- ✅ Attachment download, caching, three-state button (Download / Downloading / Open) + FileProvider sharing
- ✅ Auto-decryption for encrypted ZIPs (zip4j): tries master password, prompts on failure
- ✅ Decrypted artifacts stay in `cacheDir/decrypted/`, wiped on every app launch

### Send State Machine & Drafts

- ✅ Four send states: `PENDING → SENDING → SENT / FAILED`
- ✅ Failed bubbles highlighted in red with one-tap retry
- ✅ Per-task drafts auto-persisted to DataStore

### Experience Details

- ✅ Command template management (DataStore JSON storage): CRUD + reorder, one-tap fill into new task
- ✅ Auto crash reporting (opt-out): Routes crash dumps + recent log tail through your SELF SMTP
- ✅ UI language switching (per-app locale) with full string localization

### Engineering Foundation

- ✅ 11-module architecture: `app` / `core:{model,common,database,datastore,mail,data,ui}` / `feature:{tasks,newtask,settings}`
- ✅ Convention Plugins + Version Catalog (Kotlin DSL)
- ✅ Logging infrastructure: Debug → Logcat, Release → Logcat + RollingFileLogger (512KB × 3)
- ✅ `TaskRouter` / `SubjectNormalizer` unit tests (35 cases)
- ✅ GitHub Actions CI: `assembleDebug` + unit tests on every push / PR

## ⚠️ Known Limitations

1. **Sent-side attachments** are streamed from `content://` URIs without local persistence; tapping a sent attachment shows "not downloadable" (planned for next release)
2. **Android 14+ Foreground Service** — enabling realtime push requires manual battery whitelist, otherwise the system may reclaim the Service
3. **Gmail** requires an App Password (generate under account security settings after enabling 2FA); plain passwords are blocked by Google
4. **IMAP IDLE** is experimental; long-term background stability is still under observation. Default remains 30s polling + 15min WorkManager dual-track
5. **Multi-agent routing** is not implemented on the App side — use `@mention` in mail body and let your home AI gateway dispatch
