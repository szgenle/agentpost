# AgentPost v0.1.0 —— 首个开源版本 🎉

> 📖 Language · 语言：**简体中文** · [English](v0.1.0.en.md)
>
> **发布日期**：2026-05-XX（待定）
> **代号**：First Mail

AgentPost 的首个公开版本。这是一个用**标准邮件协议**作为异步通道的 Android 应用，专为"在外远程控制家里 AI 智能体"而生——把邮件客户端的通用能力，重新包装成一个聚焦"任务下发 / 结果回收"的移动端控制台。

---

## ✨ 核心亮点

- 📮 **纯标准邮件协议**：IMAP + SMTP，零自定义协议、零自定义 header，**任何邮箱都能用，家里 AI 零改造**
- 🧵 **按任务聚合**：首屏是任务池而非收件箱；详情是时间线而非气泡；Message-ID 线程链 + Subject 去 `Re:` 双路路由
- ⚡ **双模同步 + 智能实时推送**：默认 30s 前台轮询 + 15min 后台 WorkManager；可开启 IMAP IDLE 实时推送，内置**自适应心跳学习**（30s~9min 动态调节，追求"尽量接近纯 IDLE、同时不漏邮件"的平衡点）
- 🔒 **隐私优先**：凭据存 `EncryptedSharedPreferences` + Android Keystore；崩溃上报走 SELF 邮箱回传，不依赖任何三方平台
- 🌐 **中英双语**：简体中文 + English 全链路覆盖，per-app locale 独立切换

---

## 🚀 功能清单

### 邮件与任务

- ✅ 账号配置：SELF（发信方）+ AGENT（收件方）双账号，IMAP / SMTP 分离配置
- ✅ 任务创建与回复：Markdown 语法支持、附件选择（上限 10MB）、模板一键填充
- ✅ Message-ID 线程路由 + Subject 兜底 + 「未分类」面板三级兜底
- ✅ 任务列表：卡片化布局、未读角标、最后消息摘要、相对时间戳
- ✅ 任务详情：时间线渲染、Markdown + 代码高亮、附件内嵌预览入口

### 任务归档（完整闭环）

- ✅ **已归档二级页**：任务列表顶栏溢出菜单（⋮）→「已归档」，独立页面展示，每项支持「恢复」操作
- ✅ **详情页单任务归档**：任务详情 ⋮ 菜单一键归档，归档后自动返回列表 + Snackbar 提示
- ✅ **首页长按批量归档**：长按任一任务卡进入多选模式，支持多选 / 全选 / 批量归档；返回键自动退出选择态；批量部分成功有分别反馈
- ✅ **已归档硬删除**：已归档页支持彻底删除任务及其全部消息与附件
- ✅ 所有路径显式过滤 `__UNCLASSIFIED__` 占位任务，避免兜底容器被误归档

### 同步与通知

- ✅ 前台 Coroutines 30s 轮询 + 后台 WorkManager 15min 兜底
- ✅ **IMAP IDLE 智能实时推送**（实验性）：Foreground Service + 常驻通知保活；**自适应心跳学习算法**——根据每轮 `idle()` 返回时"是服务器主动唤醒还是心跳 kick 唤醒 + 是否真收到新邮件"两维信号动态调节心跳（命中新邮件×2 拉长、心跳空转×2 压缩、空闲期 ×1.2 缓慢延长），30s 下限 / 9min 上限；断连指数退避重连
- ✅ 系统通知 + 深链跳转任务详情；支持 Android 13+ `POST_NOTIFICATIONS`
- ✅ 下拉刷新（Material 3 `PullToRefreshBox`）

### 附件与加密

- ✅ 附件下载、缓存、三态按钮（下载 / 下载中 / 打开）+ FileProvider 分享
- ✅ 加密 zip 自动解密（zip4j）：设置主密码后自动尝试，失败弹框手输
- ✅ 解压产物仅落 `cacheDir/decrypted/`，每次启动全量清除

### 发送状态机与草稿

- ✅ 发送四态：`PENDING → SENDING → SENT / FAILED`
- ✅ 失败气泡红色高亮 + 一键重试
- ✅ 按任务分 key 的草稿自动持久化到 DataStore

### 体验细节

- ✅ 命令模板管理（DataStore JSON 存储）：CRUD + 上下排序，新建任务页一键填入
- ✅ 崩溃自动上报（可关）：通过你自己的 SELF 邮箱 SMTP 回传崩溃报告 + 最近日志尾
- ✅ 中英文界面切换（per-app locale）+ 完整文案本地化

### 工程基建

- ✅ 11 模块多模块架构：`app` / `core:{model,common,database,datastore,mail,data,ui}` / `feature:{tasks,newtask,settings}`
- ✅ Convention Plugins + Version Catalog（Kotlin DSL）
- ✅ 日志基础设施：Debug 走 Logcat，Release 走 Logcat + RollingFileLogger（512KB × 3）
- ✅ `TaskRouter` / `SubjectNormalizer` 单元测试（35 用例）
- ✅ GitHub Actions CI：`assembleDebug` + 单测在每次 push / PR 运行

## 📦 安装

### 从源码构建

```bash
git clone https://github.com/szgenle/agentpost.git
cd agentpost
./gradlew :app:assembleDebug
# APK 产物：app/build/outputs/apk/debug/app-debug.apk
```

### 预编译 APK

附加在本 Release 的 Assets 中，直接下载安装即可。

## ⚠️ 已知限制

1. **发送端附件** 当前从 `content://` URI 读取字节流发送，本地不落盘；已发送附件点击会提示"不可下载"（下一版规划）
2. **Android 14+ 前台服务** 启用实时推送需要手动加入电池白名单，否则系统可能回收 Service
3. **Gmail** 需使用 App Password（2FA 后在账户安全设置里生成）；普通密码已被 Google 强制禁用
4. **IMAP IDLE** 是实验功能，长期后台稳定性仍在观察中；默认保持 30s 轮询 + 15min WorkManager 双轨
5. **多 Agent 路由** 不在 App 层实现，需在家里 AI 端通过邮件正文 `@mention` 自行分发
