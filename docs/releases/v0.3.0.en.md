# AgentPost v0.3.0 — Bottom Tabs & Sync Hardening 🧭

> 📖 Language · 语言：[简体中文](v0.3.0.md) · **English**
>
> **Release Date**: 2026-09-20
> **Codename**: Tabbed Inbox

Following v0.2.0 "Portable Mail" (which delivered config migration and signed releases), v0.3.0 focuses on **getting there faster and staying online more reliably**: a **bottom navigation bar** puts Tasks / Archived / Settings one tap away; a batch of IMAP sync hardening (**UIDVALIDITY validation with automatic backfill**, error-classified retries, full inbox rescan) root-causes the insidious "no new mail after switching mailboxes / server-side INBOX rebuild" problem; the push service gains a **boot receiver + watchdog + wake lock** triple safety net, plus a new **LAN presence beacon**. And it fixes a problem you can't see: the APK shrinks from 73MB back down to ~34MB.

---

## ✨ Highlights

- 🧭 **Bottom navigation bar**: Tasks / Archived / Settings promoted to three top-level tabs, one tap away; per-tab state is preserved across switches, and the bar auto-hides on drill-down pages
- 🔁 **IMAP UIDVALIDITY auto-backfill**: detects a server-side INBOX rebuild, backfills only the last 7 days of mail, corrects the sync watermark and resumes pure incremental fetching — root fix for "no new mail after switching mailboxes / INBOX rebuild"
- 🛡️ **Triple keep-alive for push**: boot-time autostart (BootCompletedReceiver) + WorkManager watchdog health checks + wake lock; the service resurrects itself after aggressive ROM killers or an accidental task-card swipe
- 📡 **LAN presence beacon** (lan-beacon v0.2.0): announces device presence on the local WiFi, with an on/off switch, configurable port and live local IP display in Settings
- 🧹 **Inbox self-rescue toolkit**: a "Re-fetch everything" button in mail settings fixes missed mail; one-tap clear for unclassified messages
- 📦 **Much smaller APK**: the accidentally introduced material-icons-extended dependency removed; the "Archived" tab icon is now a 1.2KB local vector asset — debug APK drops from 73.21MB back to ~34MB

## 🚀 Change List

### Navigation & UI

- ✅ **Bottom navigation bar**:
  - Three top-level tabs — Tasks / Archived / Settings — declared left-to-right in declaration order
  - Official saveState / restoreState pattern: switching back never rebuilds the page, list scroll position is preserved
  - Auto-hides on drill-down pages (detail / new task / unclassified / settings sub-pages), which exit via top-bar back or the system back gesture
  - Archived & Settings promoted from the task page's overflow menu to first-class entries; no more back buttons on their top bars
- ✅ **Task list interaction overhaul**:
  - Long-press now opens a context menu (Archive / Delete) instead of the old multi-select mode
  - Task deletion added, guarded by a confirmation dialog
  - Message content is text-selectable for easy copying
- ✅ **About dialog**: new "About" entry on the settings page shows the current app version

### Mail Sync & Push (the headline area)

- ✅ **IMAP UIDVALIDITY support**:
  - Validates the server INBOX's UIDVALIDITY and triggers backfill when a rebuild is detected
  - Backfill window covers only the last 7 days (with a fallback message count) instead of a full rescan; afterwards the watermark advances to the highest UID and fetching resumes incrementally
  - Both polling fetch and IDLE push share the same UIDVALIDITY + lastSyncUid watermark pipeline, persisted across runs
- ✅ **Fix for "no new mail after switching mailboxes"**:
  - Resetting lastSyncUid when an account slot is reused, so new mail is never permanently filtered by a stale watermark
  - Unread-based fetch filtering replaced with UID-incremental fetch
  - Handles QQ Mail alias switching that surfaces as a "mailbox change"
- ✅ **Error classification & retry policy**: permanent errors (e.g. authentication failure) fail fast and prompt for reconfiguration; transient errors (network) retry automatically instead of failing indiscriminately
- ✅ **Full inbox rescan**: a "Re-fetch everything" button on the mail settings page repairs missed mail caused by an over-advanced watermark; already-imported mail is deduplicated by Message-ID
- ✅ **A single unparseable message no longer loses mail**: FetchBatch separates successfully parsed UIDs from failed ones, so the watermark neither stalls nor skips; messages without a Message-ID get a stable synthesized ID
- ✅ **IMAP IDLE push reliability**: tighter session management with automatic reconnect, plus fuller exception logging

### Unclassified Messages

- ✅ **One-tap clear**: new clear-all button on the unclassified page with a confirmation dialog; a Snackbar reports the cleared count afterwards. Only messages and their local attachments are deleted — placeholder task rows remain, preserving sync compatibility with the mailbox

### Always Online

- ✅ **LAN presence beacon** (lan-beacon v0.2.0):
  - New toggle and port setting on the settings page, with live WiFi IP and beacon status display
  - The foreground service becomes dual-purpose: IMAP IDLE push + LAN beacon sub-component, controlled jointly by the two switches
  - Dependency switched to the JitPack release (`com.github.szgenle:lan-beacon:v0.2.0`), while the local composite build remains for development
- ✅ **Boot autostart**: new BootCompletedReceiver restarts the push service according to preferences; the service holds a partial wake lock for the long connection; if the user swipes the task card away, the service restarts within 5 seconds
- ✅ **Push watchdog**: periodic WorkManager health checks on the foreground service; if it's killed while enabled, the watchdog brings it back — built for aggressive ROMs that kill services without restarting them

### Engineering & Size

- ✅ **39MB APK slim-down**: removed the accidentally introduced `material-icons-extended` (the library ships 5000+ icons while the app uses exactly one); the "Archived" tab icon is now a local vector asset `ic_archive.xml` (~1.2KB) — debug APK drops from 73.21MB back to ~34MB, honoring the project's "no extended icons" convention
- ✅ **lan-beacon dependency hygiene**: composite source build and JitPack release run in parallel — hack on source locally, lock versions for release builds

## 🆚 Compatibility vs v0.2.0

- **Database / data formats**: no breaking changes; upgrading from v0.2.0 is a plain over-the-top install with no manual migration
- **Config export file**: the v0.2.0 first-generation export format is unchanged and fully compatible with v0.3.0 import/export
- **versionCode**: bumped from `2` to `3`; over-the-top install supported

## 📋 Requirements

| Item | Requirement |
|---|---|
| Android version | 9.0+ (API 28, ~94% device coverage) |
| Network | Access to your chosen IMAP / SMTP servers; LAN presence beacon requires the same WiFi as peers |
| Permissions | Internet / Foreground Service (data sync & LAN beacon) / Notifications / Boot autostart (optional, for persistent push) / Battery optimization exemption (for realtime push) |
| Mailbox | Any IMAP + SMTP-capable mailbox (Gmail / 163 / QQ / self-hosted, etc.) |

## 📦 Installation

### Prebuilt APK (recommended)

Download `app-release.apk` from this Release's Assets (signed with the author's keystore) and install over your existing copy.

### Build from source

```bash
git clone https://github.com/szgenle/agentpost.git
cd agentpost
./gradlew :app:assembleDebug
# Output: app/build/outputs/apk/debug/app-debug.apk
```

To produce a signed release APK locally, see the `build-release` / `sign-release` / `verify-release` targets in `Makefile`.

## ⚠️ Known Limitations

1. **Sent-side attachments** are still streamed from `content://` URIs without local persistence; tapping a sent attachment shows "not downloadable"
2. **Android 14+ Foreground Service** — enabling realtime push requires manual battery whitelist; some OEM ROMs also require granting the "autostart" permission in system settings for boot autostart and the watchdog to work
3. **Gmail** requires an App Password (generate under account security after enabling 2FA)
4. **IMAP IDLE** is still marked experimental; the watchdog has greatly improved long-session stability, but observation continues
5. **Config export** only covers accounts / templates / preferences, **not** task & message history (recover task data via mailbox sync itself)
6. **LAN presence beacon** is only visible within the same LAN; it won't work across subnets or on guest networks
