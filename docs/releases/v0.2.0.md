# AgentPost v0.2.0 —— 配置可迁移、签名可发布 🚚

> 📖 Language · 语言：**简体中文** · [English](v0.2.0.en.md)
>
> **发布日期**：2026-05-17
> **代号**：Portable Mail

继 v0.1.0「First Mail」首个开源版本之后，v0.2.0 聚焦在「**让 AgentPost 真正可以在你的设备之间搬家、可以被分发和升级**」这件事上：完整的**加密配置导入导出**、统一的**设置页分组语义**、可复用 keystore 的**签名构建与 CI 自动发布**全流程，以及一系列围绕真实使用场景打磨的细节体验。

---

## ✨ 核心亮点

- 📦 **配置导入导出（加密）**：账号、命令模板、应用偏好一键打包导出为加密文件；换机或重装后导入即用，密码复用「加密附件主密码」概念，零外部依赖
- 🗂️ **设置页分组重构**：原「其它」拆分为「邮件处理」与「应用」两组，账号 / 同步 / 模板 / 安全 / 关于的归属更直观
- 🔐 **可发布的签名 APK**：`app/build.gradle.kts` 接入环境变量驱动的 release 签名配置；本地 `make build-release` / `make sign-release`、CI 在 tag 推送时自动构建已签名 APK 并附加到 GitHub Release
- ✅ **APK 签名验证**：新增 `make verify-release` 目标，对产出 APK 与 keystore 指纹做自动比对，杜绝"发出去的 APK 不是预期 keystore 签的"低级事故
- 🎨 **自适应启动图标**：补齐 `mipmap-anydpi-v26` 自适应图标资源，Android 8+ 启动器圆角 / 圆形 / 水滴形状一致呈现
- 🔁 **IMAP IDLE 推送稳健性增强**：异常路径日志补齐 + 重连节奏优化，长时驻留更稳

---

## 🚀 变更清单

### 设置与配置（亮点变更最多的模块）

- ✅ **配置导入导出**：
  - 导出：把双账号配置（IMAP/SMTP）、命令模板、应用偏好打包为加密文件
  - 导入：选择文件 → 输入密码 → 选择合并策略（覆盖 / 跳过已存在）
  - 加密：复用主密码概念，未设置主密码会引导先创建
  - 修复了「首次导入失败、再次导入仍失败」的边缘问题
- ✅ **设置页分组重构**：将原扁平的「其它」拆分为：
  - **邮件处理**：账号、同步策略、IMAP IDLE、命令模板
  - **应用**：语言、主题、配置导入导出、关于
- ✅ **密码框占位符优化**：已保存密码时输入框显示遮罩占位符（如 `••••••••`），明确告知用户"密码已存在、留空即保留"
- ✅ 移除 Debug 专用的崩溃触发入口，避免误触

### 工程与发布

- ✅ **Release 签名链路打通**：
  - `app/build.gradle.kts` 通过 4 个 `SIGNING_*` 环境变量按需启用 release 签名，缺失时优雅降级为未签名构建
  - `Makefile` 新增 `build-release`、`sign-release`、`verify-release` 目标
  - `Makefile` 修复 `~` 在双引号内不展开导致 keystore 路径错误的隐蔽 Bug
- ✅ **CI 自动发布升级**：
  - GitHub Actions 在 `refs/tags/v*` 推送时，base64 解码 keystore → 注入密码 → `assembleRelease` → 上传 APK 到 Release，全流程零手动介入
  - `always()` 步骤兜底清理临时 keystore，避免 runner 残留
- ✅ **APK 与 keystore 指纹自动比对**：`verify-release` 用 `apksigner` 与 `keytool` 双向验证 SHA-256 指纹一致

### 体验细节

- ✅ **自适应启动图标**：补齐 `ic_launcher.xml` / `ic_launcher_round.xml` 自适应图标资源
- ✅ **IMAP IDLE 推送稳定性**：补齐异常分支日志、收紧重连退避节奏，提高弱网与长时驻留下的可靠性
- ✅ **IDLE 噪声治理**：未配置邮箱时不再产生密集的前台轮询警告日志

## 🆚 相对 v0.1.0 的兼容性

- **数据库 / 数据格式**：完全向下兼容，从 v0.1.0 升级到 v0.2.0 无需任何手动迁移

## 📋 系统要求

| 项 | 要求 |
|---|---|
| Android 版本 | 9.0+（API 28，覆盖 ~94% 设备） |
| 网络 | 能访问你选择的 IMAP / SMTP 服务器 |
| 权限 | 网络 / 前台服务（数据同步） / 通知 / 忽略电池优化（实时推送用） |
| 邮箱要求 | 任意支持 IMAP + SMTP 的邮箱（Gmail / 163 / QQ / 企业自建均可） |

## 📦 安装

### 预编译 APK（推荐）

直接下载本 Release Assets 中的 `app-release.apk`（已由作者 keystore 签名），覆盖安装即可。

### 从源码构建

```bash
git clone https://github.com/szgenle/agentpost.git
cd agentpost
./gradlew :app:assembleDebug
# APK 产物：app/build/outputs/apk/debug/app-debug.apk
```

如需本地产出已签名 release APK，参考 `Makefile` 中 `build-release` / `sign-release` / `verify-release` 目标。

## ⚠️ 已知限制

1. **发送端附件** 仍从 `content://` URI 读取字节流发送，本地不落盘；已发送附件点击会提示"不可下载"
2. **Android 14+ 前台服务** 启用实时推送需要手动加入电池白名单
3. **Gmail** 需使用 App Password（2FA 后在账户安全设置里生成）
4. **IMAP IDLE** 仍标记为实验功能，长期后台稳定性持续观察中
5. **配置导出** 仅覆盖账号 / 模板 / 偏好，**不包含**任务与消息历史（任务数据请通过邮箱本身的同步恢复）
